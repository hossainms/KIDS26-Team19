# Bronze download step

Ian asked for a medallion layout on his own branch. Raw files go in bronze, parsed tables go in silver, and analysis-ready tables go in gold.

## What changed

- Created the local `ian` branch from `main` at `295ffe6`.
- Added `R/bronze.R`. It lists each study's `matrix/` folder on the GEO download site and downloads every series matrix file into `bronze/geo/<GSE>/`. It writes one row per file to `bronze/manifest.csv`.
- Added `R/run_bronze.R`. It downloads every study in `GSE_Metadata_Inventory.xlsx`.
- Added `tests/testthat/test-bronze.R` with 6 checks. All pass.
- Added ignore rules so downloaded data stays out of git.

## Findings

- 132 of the 588 studies in `GSE_Metadata_Inventory.xlsx` failed with "cannot open URL". The four checked were multi-platform studies. Those publish one file per platform, such as `GSE995-GPL96_series_matrix.txt.gz`. Listing the folder finds them.
- `02_GPL_Platform_Inventory.R` builds the wrong folder for IDs with three or fewer digits. GSE14 needs `GSEnnn`.
- 1,161 of the 1,332 rows in `GSM_Expression_Inventory (1).xlsx` report zero features. Those are sequencing studies whose matrix file has no expression table. The counts sit in the supplementary files.
